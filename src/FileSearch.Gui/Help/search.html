Search Workflow

Run a focused search.

Use the Main tab to choose whether you are searching contents, file names, folder names, or both, then set the folder and recursion scope. Use Options and Dates only when you need tighter control.

Main Tab

Search Controls

  • The search bar reads left to right: the folder to search (click the folder icon to browse, type a path, or open the arrow for your locations and recent folders), the search box, the file types menu, and Search.
  • Search runs the search. Pressing Enter in the search box also starts it. While a search runs the button becomes Stop, which keeps any results already found.
  • Aa in the search box turns on match case; .* switches to regular-expression matching. The other modes (Unified, Boolean, PlainText) are under the search options button at the far right, together with what to search (contents, file names, folder names), subfolders, Office/PDF text, image OCR, the index, and size/date limits.
  • The status bar shows the current status, elapsed time, and whether the folder you are searching is indexed, with Add to index when it is not.

File Name Patterns

The file types menu in the search bar holds one-click patterns: all file types, source and config, documents, PDFs, and your own named scopes (New file-type scope…). Choosing one fills the include pattern, which you can also edit under Filters > Name.

Patterns are filters, not the search text. They are matched against file names, not the full folder path. Use semicolons or commas to separate multiple patterns.

*.cs
*.cs;*.xaml;*.json
*.md,*.txt
To search for a file or folder by name, change Search to File names, Folder names, or File and folder names. To limit which files are considered, use File name pattern.

Scanned or Image PDF Search

Searching *.pdf only limits the search to PDF files. It does not turn on OCR by itself. For scanned or image-only PDFs, use these settings:

  • Set Search to Contents.
  • Set File name pattern to *.pdf.
  • Keep Office/PDF enabled.
  • Enable Image OCR.
  • If Use index is enabled, make sure the indexed location was built with Image OCR enabled; otherwise use Index > Manage indexed locations... > Rebuild selected.

The Sidebar

The sidebar on the left keeps frequently used folders and searches one click away. Each section is a card with its own filter box, page controls, and Clear all; sections collapse independently and the panel scrolls as a whole. The button at the far left of the title bar (or View > Sidebar) collapses the sidebar to an icon rail; click any rail icon to reopen it on that section.

Section What it does
Locations Folders you pinned. Click one to search there; + adds a folder, and Pin this folder to locations in the folder menu pins the current one. The X on a row unpins it.
Recent folders Folders you searched recently. Click one to search there again. The X on a row removes that entry.
Favorites Files you starred from the results. Click one to open it.
Workspaces Saved setups (search, scopes, favorites, pins, and result view). + saves the current workspace; the header buttons import and export workspace files.
Indexed locations Folders covered by background indexing, with status badges and health details. Manage locations opens the management window. See Indexed Search.
Saved searches Your most recent full searches. Click one to restore the query, folder, patterns, search mode, and filters. + saves the current search without running it.

Search History

FileSearch keeps the most recent full searches and folders so repeated searches are quick. A search attempt is added to history when it starts, even if it is canceled or fails. History appears in the sidebar's Recent folders and Saved searches sections.

Quick Search

Use Quick Search for launcher-style searches from anywhere. It uses one search box, supports current folder, selected indexed locations, all indexed locations, and bounded machine metadata scopes, then closes after you act on a result.
