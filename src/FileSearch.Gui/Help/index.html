FileSearch Help

Find files, document text, and local mail.

FileSearch searches file and folder names, source files, Office documents, PDFs, EML/MSG messages, and messages inside local PST/OST stores. Use folder content indexes for repeat text searches, whole-drive NTFS indexes for name lookup, and opt-in OCR for supported images and documents.

Choose a scope

Select a folder in the search bar, choose whether subfolders are included in search options, then optionally narrow the scan with file name patterns like *.cs;*.xaml.

Use Quick Search

Press Win+Shift+F to open a small search window from anywhere. It searches indexed locations, streams results, and closes after you open, reveal, copy, pin, or drag a result.

Launch the release

Run the installed desktop app for interactive search, use the CLI executable for scripts, or let FileSearch manage the indexer and extractor helper processes.

Use the CLI

Run FileSearch.Cli.exe from the release folder for one-shot searches, structured output, index commands, workflows, and indexer status.

Pick a query mode

Unified is the default and combines content terms with fields such as type: and modified:. Boolean, PlainText, and Regex modes are also available.

Review matching files

Result cards show matching files or individual store messages and their hit lines. Select a card to load context in the preview pane; use the results toolbar to filter, sort, or group.

Fast Start

1

Enter what you want to find

Type text or an expression into the search box. Press Enter or choose Search to search.

2

Limit the file set

Use the file types menu or the name-pattern filter for globs such as *.cs, *.txt, or *.cs;*.xaml;*.md. Leave the pattern blank to consider all supported file types.

3

Choose the folder

Enter a path in the folder field or use the folder button. Open search options and turn Subfolders on when you want recursive search.

4

Inspect and refine

Select a result to see context. Use filter results or the Filters facets to narrow the current results without scanning the files again.

Unified search is the default. Adjacent content words are treated like AND; add fields such as type:email to limit the files being searched. See Query Syntax.

Common Tasks

Search by meaning with ONNX

Select a local Smart Search model, build vectors for an indexed folder, and search semantic:"authentication migration" in Unified mode with Use index enabled. Follow the Smart Search walkthrough.

Search only source files

Set File name pattern to something like *.cs;*.xaml;*.json, then search from your solution folder with subfolders enabled.

Find TODO or FIXME comments

Use Regex mode with TODO|FIXME, or Boolean mode with TODO OR FIXME.

Search an exact phrase

Use Plain text mode, or wrap the phrase in quotes in Boolean mode: "connection string".

Search from Explorer

Use File > Install Windows integration to add a FileSearch command for folders and folder backgrounds.

Speed up repeat searches

Add folders with Index > Manage indexed locations, then enable Use index. The GUI or tray indexer can keep them current in the background. See Indexed Search.

Search all indexed locations

Use Quick Search with All indexed locations when you do not remember which root contains a file.

Find files across a drive

Enable a local NTFS drive under File > Settings > Drive file-name index. Quick Search and indexed name searches can then use its saved names. See Drive File-Name Index.

Search Outlook messages

Enable document extraction and search type:email invoice in Unified mode. MSG/PST/OST are read locally without Outlook. See Outlook Mail Search for setup, previews, and limits.

Reuse a file pattern

Use New scope in the sidebar to save a named pattern such as *.cs;*.xaml, then apply it with one click before searching.

Prefer a denser layout

Use View > Style or File > Settings > Layout style to switch between Comfortable, Compact, and Vela. Compact reduces spacing; Vela adds the compact concept palette and denser shell.
