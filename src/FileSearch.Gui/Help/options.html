Options

Tune scope, speed, and matching behavior.

Most searches need only a folder and query in the search bar. Open search options for targets, matching mode, and extraction; expand Advanced for size, modified-date, and file-type limits.

Query Options

Option Behavior
Search mode Controls whether the query is interpreted as Unified (the default), Boolean, Regex, Semantic, or PlainText. Choose it under Match in search options. Semantic treats the entire input as a concept and selects indexed content search; its toggle is also beside .* in the search box.
Match case When enabled, uppercase and lowercase letters must match exactly.
Semantic result limits With Semantic enabled, the row below the search box offers Minimum score (0.00–1.00, default 0.60) and Maximum files (1–25, default 25). Higher minimum scores reject weaker matches. Click Search to apply. Settings, saved searches, and workspaces remember both values. Scores can still admit false positives; see semantic relevance scores for examples and interpretation.

Document Extraction

Option Behavior When to use it
Office & PDF text (document extraction) When enabled, FileSearch extracts supported document formats, including Office, PDF, EML, MSG, PST, and OST. When disabled, those formats are skipped. Disable it for faster source-code-only searches.
Image OCR When enabled, FileSearch uses Windows OCR to search recognized text in PNG, JPEG, BMP, TIFF, scanned PDF pages, and embedded images in Office, OpenDocument, EPUB, EML, and ZIP/archive files. MSG/PST/OST attachments are not OCR targets. Enable it for screenshots, scanned image files, scanned PDFs, image-heavy reference folders, and documents that contain screenshots or scanned attachments. Leave it off for faster searches through photo or asset folders. OCR language and scanned-PDF page limits are configured in File > Settings.
Skip unknown file types When enabled, FileSearch only scans known text/document extensions and any additional extensions you provide. Enable it when a folder contains many binary or generated files.
Additional plain-text extensions Adds custom text-like extensions such as .liquid, .tmpl, or .razor. Use it with Skip unknown file types when your project has uncommon text files.
For scanned or image-only PDFs, Office & PDF text and Text in images (OCR) both need to be enabled. A file name pattern such as *.pdf only limits the files being searched; it does not enable OCR.

File Size Filters

Minimum and maximum physical-file sizes are entered in kilobytes under search options > Advanced.

  • Min excludes files smaller than the entered size.
  • Max excludes files larger than the entered size.
  • A maximum of 0 uses the shared default 100 MiB cap. PST/OST stores are exempt from this default; a positive explicit maximum applies to them too.

Date Filters

The Modified controls under search options > Advanced filter by the physical file's modified date. Use After, Before, or both to search files changed in a specific period. These are not message-date filters for mail stores.

The Before date is inclusive for the whole selected day, so a file modified at 11:59 PM on that date still qualifies.

Indexed Search

Use index in search options lets covered searches read from the local index; live scan remains the fallback when a search is not covered. Folder content indexes and drive name indexes, background indexing, pause/resume, health, and status badges are described on the Indexed Search page.

Background Indexer

File > Settings > Drive file-name index enables name indexing per local fixed NTFS drive. Use fast administrator scan requests a one-time elevated master-file-table build; turn it off to scan readable folders without elevation. See Drive File-Name Index.

Use File > Settings to control whether FileSearch stays resident after the search window closes and whether the tray indexer starts when Windows starts.

  • Keep index updated after closing window hides the main window and keeps FileSearch running in the tray, so indexing and Quick Search stay available.
  • Start background indexer when Windows starts starts the tray indexer after user sign-in. This is not a Windows Service.
  • Pause indexing on battery, Indexer resource use, CPU limit, and Disk pause reduce background indexing impact.

Quick Search Settings

Use File > Settings > Quick Search to choose the global hotkey, default scope, whether the last scope is remembered, which indexed roots are included by the Selected indexed locations scope, and the shortcuts used inside the quick window.

  • Global hotkey can be Win+Shift+F, Alt+Space, or Ctrl+Space.
  • Default scope is used when remembering the last Quick Search scope is off.
  • Include indexed content controls whether Quick Search adds indexed file-content matches after filename and path matches.
  • Selected indexed locations controls which roots are searched by that quick scope.
  • Quick window shortcuts controls close, focus results, open, reveal, copy path, pin, and preview actions inside Quick Search.

Smart Search Model Packs

Use File > Settings > Smart Search to choose an optional local embedding model. Selecting a model starts installation automatically; Install model also starts or retries it. After download, FileSearch loads the ONNX model and runs a document/query embedding smoke test. Semantic search then runs locally.

Build Smart Search vectors for an indexed folder, then click Semantic beside .* and enter an ordinary phrase such as renewal pricing discussion. Contents and Use index are selected automatically. The explicit semantic:"your concept" syntax remains available in Unified mode. See Smart Search with ONNX for the complete setup and search walkthrough, existing model folders, and troubleshooting.

  • Disabled keeps FileSearch in classic mode with filename, metadata, indexed content, OCR, Boolean, regex, fuzzy and proximity search.
  • BGE small English v1.5 is the recommended local semantic model for English documents.
  • all-MiniLM-L6-v2 is a smaller compatibility option.
  • Local reranker applies a lightweight local ranking pass after result fusion. Turn it off to keep the raw provider-fusion order.

Model packs are stored in the configured model folder under your user profile by default. Removing the model folder disables semantic indexing until another model is installed. Use Indexed locations > Location > Smart Search to check vector coverage for a location or queue a Smart Search rebuild without changing the indexed content.

Themes

Use View > Theme to choose Light, Dark, Visual Studio, or System. Theme selection is saved and restored the next time FileSearch starts.

Display Style

Use View > Style or File > Settings > Layout style to choose Comfortable, Compact, or Vela. Comfortable keeps the larger default spacing. Compact reduces padding, control heights, and list spacing so more results and options fit on screen. Vela uses the compact concept palette, tighter cards, inline search controls, and denser panels.

Windows Integration

Use File > Install Windows integration to add FileSearch to the Windows folder context menu and Start menu. Use Remove Windows integration to remove those registrations.
