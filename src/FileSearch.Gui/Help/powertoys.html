Optional PowerToys Integration

Search from PowerToys Command Palette.

FileSearch for PowerToys is a separately installed companion that brings indexed filename and document-text searches into Command Palette. Find a file, copy matching text, or continue the search in the full FileSearch window.

PowerToys is optional. FileSearch works normally without it. The main app does not load the PowerToys SDK, check for PowerToys at startup, prompt you to install it, or change your shortcuts. The companion is separate from the normal FileSearch installers.

Set Up the Companion

  1. Install FileSearch 1.10.0 or later and add the folders you want to search under Index > Manage indexed locations. Let their folder indexes finish building. See Indexed Search.
  2. On Windows 11, install PowerToys and enable Command Palette in its settings.
  3. Install the separate, signed FileSearch.PowerToys_*.msix companion package for your release. A locally built unsigned package needs signing and a trusted certificate before normal installation.
  4. Open Command Palette using its configured shortcut. Reload Command Palette extensions if the FileSearch commands do not appear.

Installing the main FileSearch app alone does not install the companion. FileSearch's own Quick Search remains available independently.

Releases without signing credentials include an unsigned MSIX and a separate FileSearch.PowerToys_*-development.zip. For local testing on a computer with Developer Mode already enabled, extract that ZIP into a permanent folder and follow its README-DEVELOPMENT.txt to register AppxManifest.xml. Keep the folder in place until you uninstall the companion. This setup does not enable Developer Mode or change Windows security settings.

Choose a Search Command

CommandWhat to enterResults
FileSearch: file names Literal filename text, such as invoice. Matching files from existing folder indexes, with their full paths.
FileSearch: file contents Text or a Unified query, such as type:pdf invoice. Matching indexed files, with paths and short text snippets.

Results update as you type. Each new query cancels the previous search so older results do not replace newer ones. For content-query examples, see Query Syntax.

Use a Result

Press Enter to open the selected file in its default application. Open the result's action menu for these commands:

  • Open in FileSearch brings the desktop app forward with the query, indexed folder, search target, and selected file. It also works when FileSearch is already running.
  • Show in File Explorer reveals the file in Explorer.
  • Copy path copies the full file path.
  • Copy matching text copies the matching text for a content result.

A query handoff does not interrupt a search or replacement already in progress in the desktop app. Finish or cancel that operation, then choose Open in FileSearch again. If the indexed folder has been removed, the handoff does not run the query against another folder.

Configure a Portable or Custom Installation

Open the FileSearch extension's settings inside Command Palette:

  • FileSearch application: leave blank for a standard MSI installation under Program Files\FileSearch. For portable, custom, or main MSIX installations, enter the full path to FileSearch.Gui.exe.
  • Custom FileSearch index (optional): leave blank to use the standard index. Enter a full database-file path if your FileSearch installation uses a different index, then reload the extension.

The standard index is %LOCALAPPDATA%\FileSearch\Index\filesearch.db. The existing FILESEARCH_INDEX_DATABASE_PATH environment override is also supported. Companion settings are separate from the desktop app's settings and are stored in %LOCALAPPDATA%\FileSearch\PowerToys\settings.json.

Search Scope and Limits

  • The companion searches existing, compatible folder indexes and preserves their extension, directory, recursion, hidden-file, and OCR filters.
  • Existing indexed OCR text can appear in content results. The companion does not enable OCR, download models, scan the disk, start another indexer, or build or refresh indexes.
  • Whole-drive MFT filename snapshots and semantic search are not used by this version of the companion.
  • Queries return up to 50 distinct files and have a three-second search deadline. A status row indicates limited or partial results; enter a more specific query to narrow the matches.
  • Incomplete, incompatible, or unavailable indexes are skipped. Add or refresh their folders in FileSearch before trying again.

If Something Is Missing

  • No FileSearch commands: check that Command Palette is enabled, the separate companion is installed, and its extensions have been reloaded. A PowerToys Run plugin is not included with this companion.
  • No matching indexed files: check that the folder has a completed content index in FileSearch. A drive-name index alone is not enough. Check the companion's custom index setting if you use another database file.
  • Some folders need an index refresh: refresh those locations in FileSearch. The companion does not fall back to a live scan.
  • Search time limit reached: refine the query to make it more specific.
  • Open in FileSearch fails: check the FileSearch application setting, especially if you moved a portable installation.

Remove the Companion

Uninstall FileSearch for PowerToys from Windows Installed apps. FileSearch, its settings, and its indexes remain available. Removing PowerToys also leaves the normal FileSearch app usable.
